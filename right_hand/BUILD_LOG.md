## 2026-10-04 — 驅動板供電確認

- 使用者回報：驅動板接上變壓器後，板背 VCC–GND 兩焊點量得 5V。→ 組裝表 0.3 完成。板背焊盤是否為 USB 模式仍待第一次 `scan` 確認。
- Mac mini 上第一次執行 `first_scan.sh`：系統只有 Python 3.9，也沒有 Homebrew，腳本在建環境前停止。改為支援用 uv 取得 Python 3.12。
- 第二次執行：環境建立成功（Python 3.12.15、rustypot 1.10.0），序列埠為 `/dev/cu.usbmodem5B790827031`，掃描沒有伺服機回應。當時變壓器沒有插上，伺服機沒電，所以這次掃描不算數。
- 同一次執行暴露腳本在 macOS 內建 bash 3.2 上的錯誤（`$RC` 後面緊接全形括號被當成變數名），已改用 `${RC}`。
- 新增 `servo_tool.py diag`：掃不到時送 PING 並印出原始位元組，用來分辨沒電、沒接好、回音或鮑率問題。`scan` 在快速掃描沒結果時改用較長逾時逐一 ping。
- 仍未有任何伺服機上電。
