- [ ] 4.1 食指裝上 Hand plate（俯視最左），線先穿過方孔，3 顆自攻螺絲。
- [ ] 4.2 中指（中）、無名指（右），各 3 顆。裝好後檢查相鄰手指的橫桿螺絲露出端會不會互碰。
- [ ] 4.3 拇指裝上 Wrist interface，3 顆，線走內側。
- [ ] 4.4 Wrist interface 與 Hand plate 合體，4 顆。
- [ ] 4.5 串接 8 顆伺服機。
- [ ] 4.6 全手測試：需要先有全手用的人工操作工具（比照 `finger`，逐指、低速、可中止），不直接跑上游 demo。

尚未確認：

- [ ] 閉合時讀值少約 2° 是否為穩態誤差（需確認工具版本後再看一次輸出）。
- [ ] （選做）量測 USB 外殼之間的電位差。
