# QRing Hand 0.3.0：三軸方向直接連續跟隨

日期：2026-10-14（Asia/Taipei）。移除「握拳的樣子」（姿勢與幅度）與兩段模式，改成校正後的連續雙輸入：彎曲與左右側擺同時決定四指目標。這是操作者控制方法，沒有 AI 推論或直接伺服機命令。

## 行為

三軸加速度 → 四姿勢校正座標（`PalmModel`）→ 中立／端點餘裕與平滑 → `direct_targets` → 原手掌面板 HTTP 介面。

| 輸入 | 目標 |
| --- | --- |
| 握拳程度 c（0–1） | 彎曲 = −30° + 115° × c |
| 左右側擺 s（−1–1） | 食指／中指／無名指側擺 = 40° × s；拇指側擺 = −40° × s |
| 沒勾選跟隨的手指 | 張開位置（彎曲 −30°、側擺 0°） |

每指經 `clamp_finger` 限幅，維持彎曲 −30°–85°、側擺 ±40°，且兩顆馬達都在 ±90°（`abs(flex)+abs(side)≤90°`）。例如 c=0.5、s=0.5 時，彎曲 27.5°、三指側擺 +20°、拇指 −20°；握到底 85° 時側擺最多 ±5°。彎曲優先，側擺隨馬達餘裕收窄。面板還會檢查它的實際中位修正、速度、電壓、溫度、落後等限制，App 不繞過。

側擺進入中立會歸零；彎曲與側擺都會平滑，端點收斂後補送到位目標。最小變化使用既有角度門檻；側擺中立不能讓彎曲抖動繞過該門檻。每次送出前（包括節流等待後），兩個讀值都須有效且在 1 秒內。無效／過期時不送目標；斷線、停止與結束沿用關扭力流程。

## 使用與遷移

- 校正頁固定引導張開、握拳、左、右四個姿勢，每一步與最後儲存都可單擊戒指。
- 已存的 version 2 四姿勢校正可直接沿用。version 1 兩點校正仍可讀取與預覽握拳，但啟動跟隨會拒絕並要求重新做四姿勢校正。
- 舊 `fist_pose`（例如 `right_swing`）、`fist_scale` 與 `mode` 不再載入、不影響動作；API 更新這些鍵會拒絕。下次儲存設定會移除它們。其他速度、平滑、中立與輪詢設定保留。
- 不必有任何可用的已存姿勢，就能啟動。面板自身的存姿勢功能仍屬另一個操作介面。
- 啟動仍由使用者按兩次確認；安裝、連線、校正與改設定都不會自動啟用扭力。
- 控制頁呈現側擺輸入，四指呈現回讀的彎曲／側擺角度；若模擬面板沒有角度回讀，明確標為「目標」，不當成實際位置。

三軸仍只量到重力方向，因此只有兩個可觀測的方向座標，不能當成三個獨立關節角度；水平放手、平行桌面旋轉可能量不到。真實複合動作是否交叉影響、拇指與其他手指的側擺方向是否符合操作者預期，須實機操作確認。校正模型與拒絕範圍見 [側擺輸入](sway-input.md)。
